# Full-Stack Task Manager
 
This project is a task manager with a React frontend and Node.js Express backend.
 
## Features
 
- Add tasks
- View tasks
- Edit tasks
- Delete tasks
- Search tasks
- Filter by status and priority
- Sort tasks
- Task validation
- Loading and error messages
- Data is stored in a JSON file
 
## API Used
 
GET /api/tasks
 
GET /api/tasks/:id
 
POST /api/tasks
 
PUT /api/tasks/:id
 
DELETE /api/tasks/:id
 
## How to Run
 
### Server
 
```bash
cd server
npm install
node server.js
