# Blog Post Explorer
 
This project displays blog posts using the JSONPlaceholder API.
 
## Features
 
- Displays all posts
- Search posts by title
- View post details
- View comments for a post
- Loading and error messages
 
## API Used
 
https://jsonplaceholder.typicode.com/posts
 
https://jsonplaceholder.typicode.com/posts/:id/comments
 
## How to Run
 
```bash
npm install
npm run dev
